# Sklair

Sklair is a HTML compiler for websites and browser applications. Write reusable HTML components, run Lua during compilation, and generate complete pages from Markdown or data. The output is ordinary HTML, CSS, JavaScript, and static assets.

## Components are HTML

Define a component:

```html
<!-- components/Greeting.html -->
<p>Hello, <span sklair-text="name"></span>.</p>
```

Use it in a document:

```html
<Greeting name="world"></Greeting>
```

Sklair produces:

```html
<p>Hello, <span>world</span>.</p>
```

Components can include other components, accept props and body content, contribute document-head elements, and keep styles and scripts alongside their HTML.

## Capabilities

- [Components](https://sklair.numelon.com/docs/components/) with props, conditional bindings, default slots, and colocated assets.
- [Inline Lua](https://sklair.numelon.com/docs/lua/inline-lua/) with static and per-use execution, plus [pre- and post-build hooks](https://sklair.numelon.com/docs/hooks/).
- [Document generation](https://sklair.numelon.com/docs/document-generation/) through full-document layouts and the Markdown, JSON, and JSON Schema libraries.
- [Head processing](https://sklair.numelon.com/docs/sklair/head-processing/) for deduplication and ordering, and a [built-in OpenGraph component](https://sklair.numelon.com/docs/reference/opengraph/).
- Optional [runtime templates](https://sklair.numelon.com/docs/components/runtime-templates/) for cloning markup in the browser.
- A [development server](https://sklair.numelon.com/docs/getting-started/development-server/) with automatic refresh, file watching, and SPA path rewrites.

## Getting started

[Download Sklair](https://sklair.numelon.com/download/), then follow the [getting-started guide](https://sklair.numelon.com/docs/getting-started/) to create and compile a project.

```sh
sklair init
sklair build
sklair serve
```

Use `sklair --help` or `sklair help serve` for command help. For CI and hosting, see [Deploying Sklair](https://sklair.numelon.com/docs/sklair/deployment/).

## Building from source

Use the Go version specified in `go.mod` or a compatible newer version:

```sh
go build -o sklair .
```

Report compiler issues through [GitHub Issues](https://github.com/numelon-oss/sklair/issues).
