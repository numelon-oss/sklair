A whole-project compiler for HTML.

Sklair starts with real HTML documents, understands their dependencies as one project, and resolves the work the browser should never have been asked to do.

Components, props, slots, head contributions, assets, compile-time logic, and generated documents become ordinary HTML files. There is no virtual DOM, hydration pass, or mandatory client runtime left behind.

The browser only gets the finished document.

Sklair treats composition and generation as compiler work, while keeping the source recognisably HTML.

Compile-time Lua

Static work once per definition, dynamic work once per instance, and explicit trusted markup.
